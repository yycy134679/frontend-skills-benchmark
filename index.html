精品咖啡订阅官网

案例 01 / 2 个模型 / 每个 6 个结果

题解

单一庄园精品咖啡品牌 TerraBrew 的官网首页。首屏呈现哥伦比亚埃尔帕拉伊索庄园当季咖啡果枝与产区批次信息。

提示词

单一庄园精品咖啡品牌「TerraBrew」官网（1440×900 起，响应式到 390 宽）：首屏呈现哥伦比亚埃尔帕拉伊索庄园当季咖啡果枝实景与产区批次信息；往下依次展开可点击切换的八维咖啡风味轮（花香、果香、酸质、甜感、醇厚、坚果、巧克力、香料）、五步庄园溯源时间轴、带植物线稿印章的单批次凭证卡，以及深烘焙褐订阅配置器与页脚。

八维风味轮、溯源节点与订阅配置器是这件作品的核心：点击风味扇区同步切换庄园风味笔记，切换重量、配送周期和研磨方式时实时计算每次配送价格并生成配置摘要。

03

黑胶播放器

案例 03 / 6 个结果

题解

桌面端音乐 App 的「正在播放」模块。唱臂落针开始播放，拖动唱臂选段，歌词随进度逐行高亮，播放队列可以展开收起。

提示词

一个桌面端音乐 App 的「正在播放」模块，播放一张三首曲目的虚构专辑，曲目、歌手、专辑名与歌词全部虚构，每首有独立时长和逐行时间戳歌词。

唱臂从支架落到唱片开始播放，落针过程中可以抬臂取消。播放时唱片转动，暂停时减速停下。拖动唱臂可以选段：落针角度对应播放位置，拖动时显示预览时间，松手后从该处继续播放，按 Esc 取消并回到拖动前的位置。唱臂可以用方向键调整位置。

播放控制包含播放与暂停、上一首、下一首、单曲循环开关、进度拖动、音量拖动与静音，显示当前时间与总时长。一首放完自动进入下一首，开启单曲循环时重头再放。

歌词随播放进度逐行高亮并自动滚动，点击任意一行从该行的时间开始播放。播放队列可以展开收起，列出三首曲目并标出正在播放的一首，点击切换，点击面板外或按 Esc 关闭。

空格键播放暂停，左右方向键前后跳五秒。收藏与音量在刷新后保留。系统开启减弱动态效果时唱片停止旋转。

音频用 Web Audio 合成或直接内嵌在页面里，不引用外部音频文件。页面为单个 HTML 文件，样式与脚本内联，打开即可运行。

生成日期 2026-11-07。六组结果均由 Claude Code 调用 codex/gpt-6.1-terra 生成，思考强度 xhigh。对照记录保存了轮次与耗时。

Orvo 官网落地页

案例 04 / 2 个模型 / 每个 6 个结果

题解

AI 建站与应用生成工具 Orvo 的中文官网落地页。提示词只给产品事实、套餐、模板与用户案例，不指定任何视觉方向。

提示词

为 AI 建站与应用生成工具 Orvo 设计并实现官网落地页。

- 产品：用户用对话描述想法，Orvo 在几分钟内生成能上线的网站、Web 应用和 iOS / Android 应用。生成后可以继续用对话修改，一键发布到 Orvo 子域名或自有域名，代码可以完整导出。
- 受众：早期创业者和独立开发者，多数人能说清想做什么，但没有完整的设计或工程能力。
- 界面语言：中文。

和同类的两点不同：
- 专家全程带着做：每个付费项目配一位上线过产品的专家（产品、设计或工程背景），在需求梳理、上线前检查、上线后第一个月三个节点介入。Pro 每月一次 30 分钟视频评审，Unlimited 每周一次，另有专属群聊。
- 按月订阅：不按 token 或点数计费，对话修改次数不设上限。同类工具常见的做法是按用量扣点，用户改到一半额度用完，只能加购或停下。

定价（按月，月付和年付可切换，年付省 20%）：
- Starter $0：1 个项目，只能做网站，使用 Orvo 子域名，页面带 Orvo 标识，社区支持。
- Pro $24.99 / 月，年付折合 $19.99 / 月（每年 $239.88）：5 个项目，网站与 Web 应用，自有域名，导出代码，每月一次专家评审。
- Unlimited $34.99 / 月，年付折合 $27.99 / 月（每年 $335.88）：项目不限，包含移动应用，每周专家评审与专属群聊，优先生成队列，最多 3 位团队成员。

模板：共 120 个，分落地页、电商小店、预约与会员、内部工具、内容社区、移动应用六类。页面展示其中 12 个，可以按类别筛选，每个写明名称、适用场景与使用次数，并有入口查看全部。示例：「咖啡馆预约」预约与会员，已使用 3,240 次；「独立播客站」内容社区，已使用 1,870 次；「库存看板」内部工具，已使用 960 次；其余由你补全。

使用流程：描述想法 → 首版生成（平均 4 分钟）→ 对话修改 → 专家上线前检查 → 发布。

数据与用户反馈：
- 已上线项目 18,000 多个，付费项目从开始到首次上线平均 6 天。
- 三位用户的案例：林夏用 Starter 做了手作陶瓷小店，第一个月接到 41 笔订单；王拓用 Pro 做了健身教练预约工具，专家评审帮他砍掉了一半功能后两周上线；陈可和两位合伙人用 Unlimited 做了社区团购 App，iOS 版首月 2,600 次下载。每个案例配一句用户原话，原话由你撰写。

常见问题至少回答以下五个：生成的代码归谁、能不能导出；专家是什么人、怎么匹配；不限修改次数有没有使用限制；取消订阅后已上线的项目怎么办；支持哪些付款方式。

行动入口：免费开始与预约专家演示两种。免费开始可以直接输入一句想法，只做前端：输入为空时给出提示，提交后显示已收到的状态。

页面至少包含：首屏、产品能力、模板、定价、常见问题、结尾行动。

主视口为桌面 1440 宽，适配到 390 宽的手机。
