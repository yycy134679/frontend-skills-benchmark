# 三种画廊原型

打开 `index.html` 选择留白展览馆、黑橙剪辑台或纸感设计刊物。也可以在项目目录运行以下命令，然后访问 `http://127.0.0.1:8765/prototypes/`：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

上下浏览案例，使用箭头、触控板或手指左右浏览版本；点击缩略图在新标签页打开独立示意页面。展开案例信息可以查看和复制提示词。

案例和缩略图均为设计示意，不代表对应技能的真实生成结果，也不代表最终参评名单。三种风格共用内容和操作，方便比较展示网站本身。

后续开发采用纸感设计刊物风格（`gallery.html?style=journal`），视觉规范见项目根目录的 `DESIGN.md`。另外两版保留作为参考。真实案例和参评技能尚未确定。
