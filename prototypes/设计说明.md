# 原型视觉说明

后续开发采用纸感设计刊物风格；其他两版保留作为参考。三种风格共用三个真实案例，当前收录 pi 生成的无技能基准与 Anthropic frontend-design 单技能对照。

## 共同结构

三个原型共用同一内容与操作，仅视觉方向不同：

- 水平画廊：上下滚动切换案例，每组内左右滚动浏览版本，横向按卡片吸附。
- 每个案例以无技能基准排在首位；其后为 frontend-design 版本及 GitHub 仓库链接。
- 点击缩略图在新标签页打开对应案例的独立页面，保留完整交互。
- 案例信息默认折叠，展开后可见提示词（可复制）与生成信息。

## 三种视觉方向

界面克制，截图是主体。

| 用途 | Token |

## 公共交互

- 横向轨道启用 `scroll-snap-type: x mandatory`，滑动与箭头均吸附到卡片起点。
- 多个版本时提供左右箭头，逐张浏览，到两端自动禁用；仅一个版本时隐藏箭头并放大截图；两个版本桌面并排、手机横向滑动。
- 用 `sessionStorage` 记住每组横向位置与页面纵向位置，切换风格或返回后继续浏览。
- 键盘可达：`a`、`button`、`summary` 有 3px 强调色聚焦描边；选中文字用强调色。
- 展开的案例信息包含提示词与生成信息，提示词可一键复制。
- 移动端（≤760px）：箭头保留、卡片约占 86–88% 宽、副信息隐藏，黑橙剪辑台侧栏转顶部导航。
- 遵循 `prefers-reduced-motion`：关闭平滑滚动与缩略图过渡。

## 案例与版本数据

- 三个案例：寻常科技「加入我们」、同频 SaaS 官网、林间个人作品集。
- `gallery-data.js` 保存各案例的提示词和版本信息；新增技能结果加入对应案例的 `versions`。
- 当前版本由 pi 使用 `command-code/deepseek-deepseek-v4.1-flash-fast`、`high` 独立生成，分别采用无技能与指定 frontend-design 技能条件。
- 缩略图为统一的 1440 × 960 桌面首屏截图；生成信息中展示模型、提供方、工具、思考强度和日期。
- `demo.html` 与旧截图保留为早期视觉原型，不进入当前画廊。
