# 原型视觉说明

后续开发采用纸感设计刊物风格；其他两版保留作为参考。案例、截图与页面均为设计示意，不代表真实技能效果。

## 共同结构

三个原型共用同一内容与操作，仅视觉方向不同：

- 水平画廊：上下滚动切换案例，每组内左右滚动浏览版本，横向按卡片吸附。
- 版本顺序固定：无技能（基准）、frontend-design、impeccable、oil-ui；每张卡片可跳转对应技能的 GitHub 仓库（基准版除外）。
- 点击缩略图在新标签页打开独立示意页面（`demo.html`）。
- 案例信息默认折叠，展开后可见提示词（可复制）与生成信息。

## 公共交互

- 横向轨道启用 `scroll-snap-type: x mandatory`，滑动与箭头均吸附到卡片起点。
- 每组提供左右箭头，逐张浏览，到两端自动禁用。
- 用 `sessionStorage` 记住每组横向位置与页面纵向位置，切换风格或返回后继续浏览。
- 键盘可达：`a`、`button`、`summary` 有 3px 强调色聚焦描边；选中文字用强调色。
- 展开的案例信息包含提示词与生成信息，提示词可一键复制。
- 移动端（≤760px）：箭头保留、卡片约占 86–88% 宽、副信息隐藏，黑橙剪辑台侧栏转顶部导航。
- 遵循 `prefers-reduced-motion`：关闭平滑滚动与缩略图过渡。

## 示意内容性质

- 三个案例：拾页（产品介绍页）、日常账本（数据仪表盘）、林间工作室（个人作品集）。
- 四个版本：无技能（基准）、frontend-design、impeccable、oil-ui，各版本共用同一提示词与模拟数据。
- 缩略图为固定窗口截图（标注 1440 × 960），卡片与页脚均注明「示意页面 · 非评测结果」。
- 独立示意页面提供 4 种配色变体，仅用于展示差异，不代表任何技能的真实生成结果；技能版本与生成日期待真实结果加入后填写。
