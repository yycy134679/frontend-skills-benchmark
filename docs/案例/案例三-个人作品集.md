# 案例三：个人作品集

请为虚拟独立设计师「林间」制作一个完整的中文个人作品集网站。

让访客认识这位设计师、了解其创作方向与代表作品，并愿意进一步联系合作。

自主设计页面的信息组织、模块数量与顺序、视觉风格、配色、字体、图片、布局和交互。以下是内容素材，不是页面结构；可以重组、合并和提炼表达，保留关键事实。

## 个人信息

- 姓名：林间。
- 身份：独立视觉与数字产品设计师。
- 所在地：杭州，接受远程合作。
- 创作方向：品牌视觉、网站设计与数字产品体验。
- 理念：让清楚的表达，也有自己的性格。

个人介绍：我关注人与信息之间的关系，喜欢从日常观察中寻找设计的起点。从一个品牌的第一印象，到一个产品里的细小操作，我希望设计既能传达独特的气质，也能让使用变得自然。

## 代表作品

### 田野书店

- 类型：品牌视觉。
- 项目背景：一家关注文学、艺术与在地生活的独立书店，希望建立亲切、有辨识度的品牌形象。
- 设计内容：品牌标识、字体与色彩系统、书签及活动海报。
- 创作思路：从书页与田野的关系出发，用简单的视觉语言连接阅读与日常。

### 同频

- 类型：数字产品。
- 项目背景：面向自由职业者与小型团队的项目协作工具，需要让任务、讨论和进度清楚地组织在一起。
- 设计内容：信息架构、任务看板、项目概览与界面组件。
- 创作思路：减少信息噪声，让团队快速找到当前需要关注的事情。

### 慢日咖啡

- 类型：网站设计。
- 项目背景：一家社区咖啡店，希望通过网站传达轻松的空间氛围，介绍咖啡与季节菜单。
- 设计内容：品牌官网、菜单展示与移动端体验。
- 创作思路：把线下空间的节奏带到屏幕上，让浏览像一次短暂的停留。

### 城市间隙

- 类型：编辑设计。
- 项目背景：一本记录城市散步、街角店铺与日常细节的独立刊物。
- 设计内容：封面、内页排版与图文编排。
- 创作思路：通过文字与图像的节奏，让被忽略的城市细节重新进入视野。

## 基本要求

作品应有与项目内容相符的视觉展示，可以自行创作封面或设计示意。支持手机与电脑浏览，保持良好的对比度和可读性。交付可运行的前端页面，所采用的导航、作品浏览与联系入口应提供可用的演示交互，无需真实后台。标注「虚拟设计师 · 作品集演示」。
