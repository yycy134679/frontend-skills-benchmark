关于这首歌

一首写给错过的人的歌

2017 年，民谣组合房东的猫为动画《我是江小白》献唱片尾曲《云烟成雨》。一把木吉他，一副干净的嗓子，把青春里没说出口的话轻轻放进了旋律里。

歌里没有轰轰烈烈的故事，只有一句晚安、一封留在行李箱底的手写信、一条越走越长的林间小路。那些想再见一面的人，那些渐行渐远的夜晚，像云烟一样散开，又在某个时刻落成一场雨。

也正因为这份克制，它被很多人在深夜单曲循环，成了房东的猫流传最广的作品之一。

房东的猫

来自武汉的民谣组合。不追求复杂的编曲，常常只是一把吉他和清澈的人声，唱城市里普通人的心事：毕业、远行、想念，以及那些没能好好说再见的人。

《云烟成雨》延续了他们一贯的温柔与诚恳——不煽情，却让人在某个瞬间突然红了眼眶。
