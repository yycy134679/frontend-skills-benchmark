一场从云开始的雨

《云烟成雨》是民谣组合房东的猫在 2017 年发行的单曲，也是动画《我是江小白》的片尾曲。

它没有激烈的告白，也没有铺满的编曲。一把木吉他，一副干净的嗓音，唱一段慢慢变淡的关系：想念还在，人已经走远了。

云散成烟，烟落成雨。歌名本身就是一个过程——那些说不出口的话，在心里飘了很久，最后总要找个地方落下来。很多人第一次听到它，是在某个下雨的晚上：回家的车上、说完晚安之后，或者一个人走过从前常去的街。

关于房东的猫

房东的猫是来自武汉的独立民谣组合。歌大多以木吉他为骨架，嗓音干净、不加修饰，写的是很普通的日子：深夜的街道、换季的天气、来不及说出口的话。

《云烟成雨》是很多人认识这个名字的起点。它把一种很难讲清楚的情绪唱得很轻，轻到可以在任何一个下雨的晚上，安静地陪着你。
