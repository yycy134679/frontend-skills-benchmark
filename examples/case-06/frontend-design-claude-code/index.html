这首歌

一首写给“放下”的歌。不哭不闹，只是把一段过去轻轻放进雨里。

《云烟成雨》由民谣组合房东的猫演唱，2017 年作为动画《我是江小白》的片尾曲发行。故事里的人在城市里兜兜转转，片尾这首歌替他们说出了没说出口的那部分：想念还在，但已经不必再追。

编曲很克制，以木吉他为底，人声贴着耳朵唱，像深夜里一个人走过一条长长的街。旋律不靠高音取胜，而是一句一句往下落，落到最后，情绪也跟着安静下来。

发行之后，它慢慢成了很多人歌单里“下雨天必听”的那一首，也让更多人认识了房东的猫。

歌名里藏着一段变化：云聚起来，散成烟，最后落成雨。听这首歌，也像经历一遍这个过程。

云

聚

开头是悬在半空的想念。很轻，很远，看得见，却够不着。

烟

散

回忆一点点模糊，细节记不清了，只剩下大概的形状和温度。

雨

落

最后终于落下来。落地就是结束，也是一种释然。

房东的猫

来自武汉的民谣组合，由嫚嫚和少卿组成。

他们的歌大多从很小的地方写起：一间出租屋，一段通勤路，一个睡不着的晚上。声音干净，配器简单，听起来像朋友坐在身边弹琴唱给你听。

《云烟成雨》是他们流传最广的作品之一。如果你喜欢这首，可以顺着把他们的其他歌也听一听。
