关于歌曲

《云烟成雨》是民谣乐队房东的猫演唱的一首歌曲，发行于 2017 年，作为动画《我是江小白》的片尾曲而被许多人熟知。

整首歌只有一把干净的木吉他、一段轻柔的旋律和一个温和的女声。没有激烈的编曲，也没有刻意的高音，它像一场下在城市里的小雨，安静地落下来，把那些说不出口的告别与想念一点点打湿。

歌名里的“云烟”是曾经轻盈缥缈的相遇，“成雨”则是它终于落地、化作回忆的样子——相逢一场，最终各自散去。这份淡淡的遗憾，让无数听众在某个深夜里按下了单曲循环。

关于房东的猫

房东的猫是一支来自武汉的独立民谣乐队，以温柔清澈的女声与简洁的木吉他编配见长。他们的歌常常写普通人的生活：城市、旅途、离别、成长，以及那些平凡夜晚里的小情绪。

《云烟成雨》是乐队传唱度最高的作品之一。在它之后，许多人顺着这首歌找到了乐队的其他作品，也记住了这个有些俏皮的名字——就像一只住在出租屋里、安静看着窗外下雨的猫。
