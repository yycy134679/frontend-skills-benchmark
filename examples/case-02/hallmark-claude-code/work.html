森林尽头的小屋

绘本创作
一个关于回家的故事

森林尽头的小屋封面插画

每一条小路，
都有它的方向。

一只小熊走进森林，想找到传说中亮着暖灯的小屋。一路上，它遇见会说话的风、长满野花的山坡，还有愿意陪它走一段路的新朋友。

这个故事献给每一个偶尔迷路的人。希望翻开它的时候，你也能想起某个让自己安心的地方。

“慢一点走，风会告诉你答案。”
