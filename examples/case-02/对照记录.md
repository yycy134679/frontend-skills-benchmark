# 绘本插画师个人网站案例对照记录

同一份提示词、同一个模型，只改变加载的前端技能，比较六个版本的页面产物与调用开销。

## 运行条件

- 日期：2026-11-06
- 模型：`codex/gpt-6.1-terra`，思考强度 `high`
- 提示词：独立绘本插画师个人网站，首页 `index.html` 与作品详情页 `work.html`，两个页面都是单文件，样式与脚本内联，不引用外部依赖
- 隔离方式：`bench/run.sh`，每组独立进程、独立配置目录、空 MCP 配置，关闭内置技能后只挂载被测技能
- 并发方式：三路同时运行，任意一组结束后补入下一组
- 技能快照：仓库 [frontend-skills](../../frontend-skills/README.md) 目录，来源提交记录在该目录的 README

## 页面观察

六组都在 1440×900 视口下查看过首屏。共同点相当明显：米白底色配森林绿，左侧衬线大标题、右侧插画的左右分栏，插画全部用 CSS 与 SVG 的几何色块绘制，没有使用照片，页面体积因此只有十几 KB。标题都围绕「把日子画成……」展开，插画师姓名集中在林知夏与林小满。

- **无技能**：最朴素的一版，导航只有三个文字项，没有品牌字标，卷首是方形插画与圆形下滚箭头。
- **frontend-design**：增加了英文小字署名与竖排装饰字，插画用拱形框，标题写成「把日子画成一首小诗」。
- **oil-ui**：信息密度最高，顶部有 `XIAOMAN LIN` 字标与橙色强调字，圆形箭头按钮，首屏底部有一条四段的滚动字幕带。
- **design-taste-frontend**：品牌名为 `little forest`，使用胶囊按钮、旋转的圆形贴纸与右下角页码，工艺细节最多。
- **impeccable**：唯一更换背景的一组，整块浅蓝天空，红色强调句，插画压住右侧边缘。
- **hallmark**：留白最大，首屏只有红色问候、两行标题与一条细下划线链接，插画画了房子与人物。

## 说明

六组页面都没有引用外部资源，内联脚本通过 `node --check` 语法检查，首页的作品卡片都能进入 `work.html`，详情页都能返回首页。滚动区的动效、悬停状态与 390 宽窄屏表现没有逐项检查。

轮次、耗时与费用取自 Claude Code 的 JSON 输出。三路并发运行，单组耗时会互相拉长，耗时一列不能跨组比较；单次样本的费用同样受服务波动影响，不能据此判断技能优劣。

原始运行目录保存在仓库之外的 `~/Code/benchmark-runs/case-02/`，包含每组的 `result.json`、`run.meta` 与 `cfg-*` 会话记录。
