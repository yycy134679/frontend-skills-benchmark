住在森林里的信

在一片会呼吸的森林里，有一间小小的邮局，收藏着许多来不及说出口的话。

ABOUT THE STORY

每一封信，
都有想去的地方。

阿栗在森林里发现了一间被遗忘的邮局。她和住在这里的熊邮差一起，开始投递那些没有写上地址的信。

有的信要送给遥远的朋友，有的信写给还没到来的季节，还有一封，写给过去的自己。一路上，他们遇见森林里的邻居，也慢慢学会把心里的话说出来。

“只要有人愿意读，
心意就不会迷路。”

THE LATEST CHAPTER / 03

第三章：寄给春天的种子

冬天快要结束的时候，邮局收到了一封有点特别的信。

CHAPTER 03

✳   01 — 03

那天早晨，阿栗在邮筒里发现了一只小小的牛皮信封。信封没有写收件人，只有一粒圆滚滚的种子，和一张折得整整齐齐的纸。

纸上写着：“请把它寄给春天。等它开花的时候，我就知道，漫长的冬天真的过去了。”

熊邮差想了想，带着阿栗来到森林里阳光最先落下的地方。他们挖了一个小小的坑，把种子和那份盼望一起，轻轻放进了泥土里。

“春天会收到吗？”阿栗问。
“会的，”熊邮差说，“我们可以一起等。”

一粒种子，
一封写给春天的信。
