THE STORY / 创作说明

每一份心意，
都有回音。

小熊在家门口捡到一封信。信里没有名字，只有一句话：“谢谢你，让森林变得更温暖。”

为了找到写信的人，小熊带着信穿过树林，拜访了许多朋友。一路上，它发现那些不经意的善意，早已悄悄长成了森林的一部分。

这个故事献给每一个认真生活、也温柔对待世界的人。
