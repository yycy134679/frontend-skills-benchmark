03 / ABOUT THE ARTIST

你好，我是小满。
欢迎来到我的小小世界。

我喜欢散步时捡到的叶子、旧书里的气味，也喜欢观察那些容易被忽略的小事。画画的时候，我把它们一一收进故事里。

希望这些画能陪你慢下来，找到一点柔软和勇气。
