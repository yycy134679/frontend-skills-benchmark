02 / An ongoing story

森林的另一边，
有一间小小邮局。

小兔阿禾在森林边开了一间邮局。这里寄出的信不一定有地址，有时是一句没说出口的谢谢，有时是一份想和远方分享的好天气。

THE LATEST CHAPTER · 最新一章

第一章：一封没有地址的信

→

一个慢慢长大的故事，正在不定期更新。

Chapter 01

一封没有
地址的信

清晨，阿禾打开邮局的木门，发现门口放着一封信。信封上没有名字，也没有地址，只有一片被风吹落的小叶子。

“也许它还不知道要去哪里。”阿禾把信轻轻放进邮袋，决定沿着森林里的小路，替它找一找收信的人。

太阳刚刚升起来，今天的第一趟旅程就这样开始了。

03 / About the artist

你好，我是小林。

相信小小的故事，
有很大的力量。

我是一名独立插画师，喜欢画会说话的动物、安静的森林，还有生活中那些很容易被忽略的温柔时刻。

我用画笔收集故事，希望它们能陪孩子长大，也陪大人偶尔回到想象里。

Xiao Lin ✳
