01 / About the story

把温柔，
送到你身边。

一只小熊，一袋信，
和一个被月光照亮的夜晚。

夜幕降临，森林邮差小熊背起邮袋出发了。它穿过松树林，越过小溪，把一封封盛着月光的信，送到每一位朋友的窗前。这是一个关于惦念、陪伴与小小善意的故事。

03 / Behind the pages

故事的背后

小时候总觉得，收到一封信是一件很郑重的事。信纸上短短的几句话，也能让平常的一天变得闪闪发亮。

于是画了这只慢吞吞的小熊，让它在安静的夜里出发。它送去的不是多么了不起的消息，只是一点月光，一句问候，还有“我正想着你”。

希望翻开这个故事的人，也能在某个忙碌的日子里，收到属于自己的那份温柔。

With love, from the forest.
