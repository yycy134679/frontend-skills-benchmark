The story behind

把想念，送到
月亮照得到的地方。

森林里有一位小小的邮差。每当夜幕降临，她就背上邮袋，把白天没能说出口的话，送到朋友们的窗前。

《月亮邮差》是一个关于思念与陪伴的故事。我想画下那些安静的时刻：一盏亮着的灯、一封远方的来信，还有知道自己正被惦记着的温暖。
