同一份提示词、同一个模型，只改变加载的前端技能，比较六个版本的页面产物、轮次与耗时。

运行条件

  • 日期：2026-11-07
  • 模型：codex/gpt-6.1-terra，思考强度 xhigh
  • 提示词：三段式描述，交代读者对象、作品集构成、连载更新方式与三类合作；交付要求为首页 index.html 与作品详情页 work.html，两个单文件，样式与脚本内联，不引用外部依赖
  • 隔离方式：bench/run.sh，每组独立进程、独立配置目录、空 MCP 配置，关闭内置技能后只挂载被测技能
  • 并发方式：三路同时运行，任意一组结束后补入下一组
  • 技能快照：仓库 frontend-skills 目录，来源提交记录在该目录的 README

页面观察

六组在 1440×900 视口下查看过首屏。共同点是首屏都把「画给孩子，也画给大人」写进简介，标题仍然落在「把日子画成……」上，插画都用几何色块拼成。

  • 无技能：米色底配深绿，小屋与骑车的熊，圆形徽章写着给小读者和大读者，版式中规中矩。
  • frontend-design：米黄底，浅蓝天空与狐狸，左侧竖排小字与短横线标题，结构最轻。
  • oil-ui：鼠尾草绿，森林里提灯的小熊，配 ILLUSTRATION NO. 01 编号，页面有约 0.8 秒的入场动画。
  • taste-skill：插画用圆拱形框，熊和孩子共读一本书，圆形贴纸落在右下角。
  • impeccable：淡紫天空占满首屏，孩子与狐狸坐在打开的书上，红色强调句最醒目。
  • hallmark：芥末黄整屏打底，深绿夜色插画加白色相框，红色圆形贴纸压在画框边。

说明

六组页面都没有引用外部资源，内联脚本通过 node --check 语法检查，首页作品卡片都能进入 work.html，详情页都能返回。六组都覆盖了出版、杂志、速写三类作品，连载章节、三类合作与回复时间也都在页面里。滚动区的动效、悬停状态与 390 宽窄屏表现没有逐项检查。

轮次与耗时取自 Claude Code 的 JSON 输出，耗时由毫秒换算为分钟。三路并发运行，单组耗时会互相拉长，耗时一列不能跨组比较；单次样本受服务波动影响，不能据此判断技能优劣。

原始运行目录保存在仓库之外的 ~/Code/benchmark-runs/case-02/，包含每组的 result.json、run.meta 与 cfg-* 会话记录。
