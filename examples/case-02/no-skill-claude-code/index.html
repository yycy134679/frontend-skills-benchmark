森林慢车THE LITTLE FOREST EXPRESS

在森林的尽头，有一座只在清晨出现的小车站。小兔阿禾带着一只旧箱子上了车，一路遇见迷路的云、收集声音的鼹鼠，还有许多来不及说出口的心事。

LATEST CHAPTER · 最新章节

第三章　给云朵的一封信

列车驶过最高的山坡时，阿禾发现有一朵小云，正慢吞吞地跟在窗外。

“你是不是迷路了？”阿禾在车票背面写下一句话，轻轻贴在玻璃上。小云没有回答，只在窗上留下一小片雾气，像一个圆圆的拥抱。

于是阿禾又写：“没关系，我们可以一起走一段。”那天的天空，很久很久都是柔软的。

Hello, I'm Xiaoman

你好，
我是画故事的小满。

我喜欢观察树叶的形状、傍晚的灯光，和那些容易被忽略的小事。画画的时候，我总在想：如果这些平凡瞬间会说话，它们会讲什么故事呢？

现在，我在自己的小画室里，继续画画、写故事，也期待和有趣的你一起创造。
