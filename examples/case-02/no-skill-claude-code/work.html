The story behind

在树影之间，
找回慢下来的勇气。

有一天，小女孩决定暂时离开忙碌的城市，走进一片安静的森林。她跟着风走，和树木打招呼，也在一场小雨里遇见了新的朋友。

《去森林里》是一本关于独处与发现的绘本。我想把散步时收集到的气味、颜色和声音，藏进每一张画里。希望翻开它的人，也能找到属于自己的那片小森林。
