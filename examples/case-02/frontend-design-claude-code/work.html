Behind the story关于这本绘本

这个故事来自一次雨后的散步。那天没有什么特别的目的，只是慢慢走着，看见一只小鸟落在枝头，也看见阳光从叶子间漏下来。

我想把这种安静的快乐画下来：有时候，只要放慢一点，就能发现身边的世界一直在温柔地回应我们。

Let's make something lovely.
