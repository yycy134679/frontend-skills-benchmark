关于画画的人

你好，我是小满。
喜欢收集微小的美好。

独立绘本插画师，住在有很多树的城市。喜欢用颜色讲故事，也喜欢观察那些容易被忽略的小事：一片落叶、一只打盹的猫，或是一封迟到的信。

希望我的画能像一本睡前故事，在忙碌的日子里，给你留一小会儿柔软的时间。

With love, Xiaoman
