月亮捎来一封信

一封从月亮上寄来的信，一段关于想念、等待与陪伴的小小旅程。

A letter from the moon
作品类型绘本故事
创作主题想念与陪伴
创作形式文字 / 插画
About this story

有些想念，
会绕过很远的路来到身边。

小女孩阿禾很想念住在远方的奶奶。一个安静的夜晚，她在窗台上发现了一封信，信封上画着一弯小小的月亮。

她和狐狸朋友循着月光出发，穿过山坡和树林，慢慢发现：那些没有说出口的想念，也会被好好收藏。

“抬头看看月亮吧，
我们看见的是同一束光。”

— A letter from the moon —
