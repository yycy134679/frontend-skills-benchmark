去山里散步

A Walk in the Mountains

带上好奇心，走进一座会呼吸的山。
在漫长的一天里，发现微小而闪亮的事。

项目类型原创绘本
创作时间2025
创作内容故事 / 插画

走慢一点，
山会告诉你。

一个女孩和她的小猫，决定暂时离开熟悉的街道，去山里走一走。她们没有目的地，只是跟着风、影子和鸟鸣，发现一路上藏着的小小惊喜。

内页跨页 / 走进山里01 — 02
内页跨页 / 停下来看看03 — 04

关于这个故事

这个故事来自一次没有计划的散步。那天的风很轻，路边的野花开得正好，我想把这种不赶时间的心情留在画里。

我用柔和的色彩和简单的形状，画下人与自然相处的片刻。希望翻开它的人，也能想起自己曾经遇见过的那座山。

让我们一起讲故事。
