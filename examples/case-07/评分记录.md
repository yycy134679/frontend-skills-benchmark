# 22 岁生日祝福网页评分记录

按 [评分规则](../../评分规则.md) 给六组成品打分。分数只代表这一次生成的成品，不代表技能本身的水平。

## 评分条件

- 评分日期：2026-11-09
- 评分模型：Claude Opus 5.5（`claude-opus-5-5`）
- 规则版本：v1
- 验收方式：Claude Code 内置浏览器，1440×900 桌面视口，从头滚到尾并逐项操作；首屏以画廊预览图为准，预览图在页面加载 6 秒后截取。
- 说明：六组页面同源打开，taste-skill 与 impeccable 用了同一个愿望存储键，测试时会读到对方存下的愿望。每组测试前都清空了本地存储并重新加载，这一点不算页面缺陷。
- 麦克风：点击后会弹出系统授权，验收时没有实际开启。麦克风吹气、拒绝授权后回退为点击，这两项按源码判断。

## 校准

按总分排序为 impeccable 89、frontend-design 87、oil-ui 87、hallmark 86、taste-skill 85、无技能 84，与整体印象一致。六组用了同一个模型，功能几乎都做全了，视觉方向也都落在暖色纸面加手绘插画，所以分差只有 5 分，全部在 80–89 档。impeccable 的手册感最强，排在第一；无技能组插画种类最多，但版式最接近模板。
