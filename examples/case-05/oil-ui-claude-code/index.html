slugify-zhOPEN SOURCE

把中文标题转成网址片段的开源库。处理多音字、标点和长度截断，压缩后 4 KB，没有依赖。

持续维护

04

周末菜单WEEKEND MENU

按冰箱里剩下的食材推荐菜谱的小程序。做过一万八千个用户，2024 年停止维护。

停更原因：食材库要一直人工校对，维护成本高于它能带来的收入；小程序类目审核也越来越难。代码留在 GitHub，没有删。
