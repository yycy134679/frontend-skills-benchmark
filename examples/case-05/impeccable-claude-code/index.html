最近在做的事

更新于 2026.10.28
开发日志每周日写，收入每月 1 日更新。这里不保证都是好消息。

拾页 2.0 是今年唯一的主线。同步层已经从 iCloud 迁到自建服务，阅读列表与高亮编辑器正在重写。历史数据比预想中脏，最近两周都在处理 2019 年留下的重复高亮。

产品之外，我在练习把话说短。每周的开发日志会写清楚这周推进了什么、卡在哪里、下周做什么；月底的一封信里，会附上收入和这个月真正有用的东西。

今年的目标不是做更多，
而是把拾页做完。
