## 说明

六个页面都是可离线打开的单文件，样式、脚本与图片内嵌，内联脚本通过 `node --check` 语法检查。`hallmark` 版本在页脚保留了一条 Wikimedia 的图片来源链接，不影响页面运行。

轮次、耗时与费用取自 Claude Code 的 JSON 输出，费用按接口返回的计费口径记录；页面大小为磁盘上的实际字节数，包含内嵌图片，因此体积差异主要反映图片使用方式，不直接代表设计质量。

每组只运行了一次，耗时与费用受服务波动影响，不能据此判断技能优劣。本轮没有做视觉评分，页面的排版、配色与交互质量需要人工查看后另行记录。

原始运行目录保存在仓库之外的 `~/Code/benchmark-runs/case-01/`，包含 `result.json`、`run.meta` 与完整会话记录。
