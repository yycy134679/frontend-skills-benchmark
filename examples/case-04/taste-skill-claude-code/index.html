GOOD TO KNOW

你可能还想知道。

开始之前，把问题问清楚。

生成的代码归谁？可以导出吗？

你拥有自己项目生成的代码。Pro 和 Unlimited 支持完整导出代码，你可以自行保存、继续开发或迁移。

专家是什么人？怎么匹配？

专家来自产品、设计或工程领域，都有实际上线产品的经验。我们会根据项目的需求和所处阶段，为每个付费项目匹配合适的专家。

不限修改次数，有没有其他使用限制？

所有计划的对话修改次数不限，不按 token 或点数扣费。各计划仍有项目数量、产品类型和团队人数等范围限制；使用时也需遵守平台使用规则。

取消订阅后，已经上线的项目怎么办？

取消后，付费功能会保留到当前计费周期结束。建议在到期前导出代码并检查域名和项目状态；后续可用功能取决于届时使用的计划。

支持哪些付款方式？

付费计划支持信用卡和借记卡付款。可用卡种及具体付款方式以结账页面显示为准。

我需要会写代码吗？

不需要。你可以用日常语言描述需求、修改页面并发布；如果你会写代码，也可以在支持的计划中导出后继续开发。
