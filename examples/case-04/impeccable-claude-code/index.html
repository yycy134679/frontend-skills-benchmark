开始之前，把重要的事情说清楚。

生成的代码归谁？可以导出吗？

你拥有自己项目的代码。Pro 和 Unlimited 支持完整代码导出，你可以将它带到自己的开发环境中继续使用。

专家是什么人？怎么匹配？

专家来自产品、设计或工程领域，都有真实的产品上线经验。我们会结合你的项目需求和当前阶段，匹配合适的专家；付费项目在需求梳理、上线前及上线后第一个月都能获得支持。

不限修改次数，有没有使用限制？

对话修改不按次数、token 或点数扣费。请合理使用服务；项目数量和可创建的产品类型仍以所选套餐为准。

取消订阅后，已上线的项目怎么办？

取消前建议先导出需要保留的代码，并确认项目使用的域名和套餐功能。取消后的项目托管与域名状态，以账户中的订阅和服务说明为准。

支持哪些付款方式？

可用的付款方式会在订阅结账时显示，具体选项可能因所在地区而异。你也可以在预约演示时向我们咨询。

我完全不会写代码，也可以使用吗？

当然。用日常语言描述你要做的事情就可以开始。付费项目还有专家陪你梳理需求，并在上线前帮你检查。
