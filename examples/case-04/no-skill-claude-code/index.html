06 / GOOD TO KNOW

你可能还想知道。

开始之前有问题很正常。我们把重要的事，先说清楚。

生成的代码归谁？可以导出吗？

你创建的项目和生成的代码归你所有。Pro 和 Unlimited 均支持完整代码导出，你可以自行保存、修改和部署。

专家是什么人？怎么匹配？

专家来自产品、设计或工程领域，都有实际产品上线经验。我们会根据你的项目类型、所处阶段和需要的帮助，为每个付费项目匹配合适的专家。

不限修改次数，真的没有使用限制吗？

对话修改次数不设上限，也不会按 token 或点数收费。各方案仍有对应的项目数量、产品类型和功能范围；请正常使用服务，避免影响其他用户。

取消订阅后，已上线的项目怎么办？

取消后当前付费周期内仍可使用已购功能。周期结束后，付费功能及自有域名等服务将不再可用；建议在到期前导出代码并妥善保存项目内容。

支持哪些付款方式？

支持主流国际信用卡和借记卡。结算时会显示当前可用的付款方式。

我需要会写代码或者设计吗？

不需要。用自然语言描述需求就可以开始；如果你会写代码，付费方案也支持导出代码，继续自由开发。
