常见问题

你可能还想知道。

开始之前，先把关心的事情说清楚。

生成的代码归谁？可以导出吗？

你创建的项目和代码归你所有。Pro 和 Unlimited 支持完整导出代码，你可以自行托管或继续开发。

专家是什么人？怎么匹配？

专家来自产品、设计或工程领域，都有产品上线经验。我们会根据你的项目类型、当前阶段和需要的帮助匹配合适的专家。Pro 每月一次 30 分钟视频评审；Unlimited 每周一次，并有专属群聊。

不限修改次数，有没有使用限制？

所有方案的对话修改次数不限，也不按 token 或点数扣费。为保障服务稳定，使用需遵守平台规则；项目数量和可创建的产品类型依所选方案而定。

取消订阅后，已上线的项目怎么办？

取消后，你的付费权益会持续到当前计费周期结束。之后项目将受免费方案限制；建议在到期前导出代码，并检查自有域名和超出免费额度的项目。

支持哪些付款方式？

支持使用主流信用卡和借记卡付款。具体可用方式以结账页面显示为准。
