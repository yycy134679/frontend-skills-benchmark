# Orvo 官网落地页案例对照记录

同一份提示词、同一个模型，只改变加载的前端技能，比较六个版本的页面产物与调用开销。

## 运行条件

- 日期：2026-11-07
- 模型：`codex/gpt-6.1-terra`，思考强度 `xhigh`
- 提示词：AI 建站与应用生成工具 Orvo 的官网落地页；给出产品能力、两点差异、三档套餐权益与年付折合价、120 个模板的分类与示例、使用流程、数据与三位用户案例、五个必答问题和两种行动入口，不指定任何视觉方向
- 交付要求：单文件 `index.html`，样式与脚本内联，不引用任何外部资源
- 隔离方式：`bench/run.sh`，每组独立进程、独立配置目录、空 MCP 配置，关闭内置技能后只挂载被测技能
- 并发方式：三路同时运行，任意一组结束后补入下一组
- 技能快照：仓库 [frontend-skills](../../frontend-skills/README.md) 目录，来源提交记录在该目录的 README

## 页面观察

六组在 1440×900 视口下查看过首屏。共同点比前几个案例更明显：标题都是「好想法 / 你的想法」加「上线」的句式，首屏左侧都放一个可以直接输入想法的免费开始输入框，五组在右侧或下方画了一个浏览器窗口样机，样机里多是植物或陶器的小店页面。除 frontend-design 外，五组都用米白底配深绿或橄榄绿。

- **无技能**：米白底深绿，标题「好想法，值得上线。」里「上线」用橙色衬线字；右侧浅绿面板放浏览器样机与「你的首版已就绪」浮卡，首屏底部是 18,000+ 与 6 天两项数据。
- **frontend-design**：唯一的白底配亮蓝，标题分两行「想法，开工。上线，有人同行。」，第二行整行蓝色；右侧淡紫色斑块托着样机，底部一行写着不按点数计费、修改不限次数、代码可导出三项勾选。
- **oil-ui**：标题字号最大，「好想法，就该被做出来。」占满左侧两行，简介和演示入口挪到右侧；输入框与样机一起放进下方整宽的浅绿面板，用户头像与项目数落在首屏下沿。
- **taste-skill**：标题「你的想法，可以上线了。」里「上线了」用橙色斜体；输入框最宽，右侧单独放 18,000+ 与「认识你的专家伙伴」入口，工作区样机从首屏下方露出一半。
- **impeccable**：标题第二行「值得真的上线。」用橄榄绿；右侧面板做成上圆下方的拱形，样机上贴着荧光绿圆形贴纸和一条对话修改的浮卡，首屏底部是三项数据。
- **hallmark**：深绿标题「好想法，尽管上线。」，输入框是带标签的多行文本框；右侧绿色面板里的样机写的是中文小店页面，首屏下方是四格数据条。

## 验证

用 Playwright 在 1440×900 视口逐组实测：

- 六组都只有一个 `index.html`，没有引用外部图片、字体或脚本；内联脚本通过语法检查，加载与操作过程中控制台没有报错。
- 定价切换：六组切到年付后 Pro 与 Unlimited 显示 $19.99 与 $27.99，切回月付后恢复 $24.99 与 $34.99。
- 模板筛选：六组点「内部工具」后只剩「库存看板」可见，「咖啡馆预约」与「独立播客站」被隐藏。
- 免费开始输入框：六组空提交都给出「先写下一句你的想法」一类的提示，填入内容后都显示已收到的状态，页面没有跳转。impeccable 与 hallmark 在空提交时给输入框加了 `aria-invalid`，其余四组没有。
- 常见问题：六组用 `<details>` 写了五到六个问答，提示词要求的五个问题都在。
- 内容核对：六组都写进了年付全年总价 $239.88 与 $335.88、三个模板示例的使用次数、林夏、王拓、陈可三个用户案例和 18,000 多个项目。
- 宽度：六组在 1440 与 390 宽下页面都没有横向滚动。390 宽下模板筛选按钮排成一行超出屏幕，靠所在容器横向滑动查看；hallmark 与无技能组的筛选按钮会换行。
- 「预约专家演示」入口、悬停状态和滚动动效没有逐项检查。

hallmark 组在输出目录里额外创建了 `.hallmark/salt`（9 字节），是技能自己写的文件，没有归档。每组 `result.json` 第一行都有一条 `unrecognized_model` 警告，JSON 在第二行，核验脚本能正常读取。

轮次、耗时与费用取自 Claude Code 的 JSON 输出。oil-ui 用了 51 轮、1.68 美元，是其余五组的三到五倍，原因没有展开分析。三路并发运行，单组耗时会互相拉长，耗时一列不能跨组比较；单次样本的费用同样受服务波动影响，不能据此判断技能优劣。

原始运行目录保存在仓库之外的 `~/Code/benchmark-runs/case-04/`，包含每组的 `result.json`、`run.meta` 与 `cfg-*` 会话记录。
