07 / 你可能想问

问题，我们
先回答在这里。

开始之前有疑问很正常。好的作品，也从一个好问题开始。

生成的代码归谁？可以导出吗？

你拥有自己项目的代码。Pro 和 Unlimited 可以完整导出代码，方便你自行维护、迁移或继续开发。

专家是什么人？怎么匹配？

专家来自产品、设计或工程领域，都有实际产品上线经验。我们会根据你的项目类型、当前阶段和需要的帮助进行匹配。Pro 每月一次 30 分钟视频评审；Unlimited 每周一次，并提供专属群聊。

不限修改次数，有没有使用限制？

所有方案的对话修改次数不限，也不会按 token 或点数扣费。不同方案仍有项目数量、可创建的产品类型和团队人数等范围限制；为保障服务稳定，使用时需遵守平台的合理使用规则。

取消订阅后，已上线的项目怎么办？

取消后会在当前付费周期结束时停止续费。建议在到期前导出代码并备份项目；自有域名、项目数量等付费功能的使用会受所选方案影响。具体保留和迁移安排以服务条款为准。

支持哪些付款方式？

支持主流国际信用卡和借记卡付款。具体可用方式会在结账时根据你的地区显示。

我需要懂设计或编程吗？

不需要。用日常语言描述你的目标即可；你可以通过对话不断调整，付费方案还可以在关键节点获得专家帮助。
